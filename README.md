# Clean Sweep

A WordPress admin plugin to bulk clean unused themes, plugins, orphan thumbnails, post revisions, transients, auto-drafts, spam comments, and orphan post meta — with automatic backups.

## Features

- **Unused Themes & Plugins**: Identify inactive themes and plugins, view their size, and delete them safely.
- **Media Cleanup**: List image attachments with thumbnails and remove the ones you no longer need.
- **Database Cleanup**: Remove post revisions, auto-drafts, trashed posts, spam comments, orphan post meta, and expired transients.
- **Automatic Backups**: Themes and plugins are zipped; database rows are exported to SQL files before deletion.
- **Modern Admin UI**: Tabbed dashboard with search, card grid, active/inactive badges, and bulk selection.

## Installation

1. Download the latest `clean-sweep.zip` from [Releases](https://github.com/mrshahbazdev/clean-sweep/releases).
2. Upload and extract to `wp-content/plugins/clean-sweep/`.
3. Activate the plugin in WordPress.
4. Navigate to **Tools > Clean Sweep**.
